A missing file is not an error — the drawer renders a labelled placeholder instead — so
you can add these one at a time.

## Recommended

Wide screenshots around **2:1** (e.g. 1880×950) look best, since screenshots render at their
natural aspect ratio. If your capture has a different ratio, add `width` and `height` to the
matching screen entry in `lib/content.ts` so the space is reserved correctly before load.
